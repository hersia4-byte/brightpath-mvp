# Client Intake Form — 15-Minute Setup Call

Fill this out on a call with the director. Every answer maps to a `{{VARIABLE}}`
in `prompts/system-prompt.md`. Read their website first and pre-fill what you
can — the call should be confirmation, not homework for them.

## Basics

| Variable | Question | Answer |
|---|---|---|
| `CENTER_NAME` | Exact name as answered on the phone | |
| `CITY_STATE` | City and state | |
| `DIRECTOR_NAME` | Who should callbacks reference? | |
| `HOURS` | Days and hours, incl. holiday closures worth mentioning | |
| `ADDRESS_AND_PARKING` | Address + any parking/entrance instructions | |

## Programs & money

| Variable | Question | Answer |
|---|---|---|
| `AGES_SERVED` | Youngest and oldest ages accepted | |
| `PROGRAMS_SUMMARY` | Rooms/programs, 1 line each (infants, toddlers, pre-K, after-school) | |
| `TUITION_SUMMARY` | Rates they're comfortable stating on the phone (or "discussed at tour") | |
| `CURRENT_OPENINGS` | Which rooms have space right now? (update monthly!) | |
| `WAITLIST_POLICY` | Waitlist? Fee? How it works | |

## Policies

| Variable | Question | Answer |
|---|---|---|
| `MEALS_POLICY` | Meals provided? Allergy accommodations statement | |
| `SICK_POLICY` | The 1-paragraph version parents get | |
| `LICENSE_INFO` | License number/accreditations to state if asked | |
| `RATIOS` | Staff:child ratios by room | |
| `CURRICULUM_BLURB` | 2 sentences on philosophy (their words, from their site) | |
| `EXTRA_FAQS` | Top 5 questions their front desk actually gets, with answers | |

## Operations

| Variable | Question | Answer |
|---|---|---|
| `TOUR_SLOTS` | When do they give tours? (e.g., "Tue/Thu 10am–2pm") | |
| `EMERGENCY_TRANSFER_NUMBER` | Number to forward emergencies to during hours | |
| `GREETING` | Confirm the first message wording (read it to them) | |

## Also collect (not prompt variables)

- Where tour bookings should go: email, and calendar if they use one
- Cell number for the daily/weekly summary text or email
- Forwarding preference: **after-hours only**, **no-answer after 4 rings**, or 24/7
- Who at the center is the day-to-day contact for tweaks
- Confirm: "Your phone greeting should mention calls may be recorded — want me
  to include that in Sunny's greeting instead?" (required in two-party-consent
  states)

## Before go-live checklist

- [ ] All variables substituted, prompt proofread aloud
- [ ] Test calls: tuition question, tour booking, absence message, emergency
      escalation, off-script question, "are you a robot?"
- [ ] Summary email/text arriving at the right address
- [ ] Forwarding tested from the center's actual line
- [ ] Director has your cell for week-one concerns
